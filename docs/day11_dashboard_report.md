# Day 11 — AtmoSync Analytics Dashboard

## 1. Objective

The objective of Day 11 was to transform the analytical outputs generated during the previous stages of the AtmoSync project into an interactive monitoring dashboard.

The dashboard combines telemetry analysis, environmental risk, spoilage risk, machine learning predictions, prediction confidence, container-level analysis, commodity-level analysis, and spoilage arbitrage decisions.

## 2. Technology

The dashboard was developed using:

* Python
* Pandas
* Streamlit
* Plotly

## 3. Data Sources

The dashboard uses the following processed datasets:

* `iot_telemetry_features.csv`
* `prediction_monitoring.csv`
* `arbitrage_decisions.csv`

These datasets were generated during the previous stages of the AtmoSync pipeline.

## 4. Dashboard KPIs

The dashboard provides key monitoring indicators including:

* Total telemetry records
* Predicted anomalies
* High and critical risk records
* Potential arbitrage opportunities
* Average environmental risk
* Average ML prediction confidence

The current telemetry dataset contains 1,785 records.

## 5. Condition Monitoring

The ML prediction monitoring dataset contains:

* 1,249 predicted NORMAL records
* 352 predicted WARNING records
* 184 predicted ANOMALY records

The dashboard visualizes this distribution for operational monitoring.

## 6. Sensor Analytics

The dashboard provides time-based visualizations for:

* Temperature
* Humidity
* Vibration

These visualizations allow sensor behavior to be explored across the simulated telemetry period.

## 7. Spoilage Risk Analytics

The feature-engineered dataset contains:

* 890 LOW risk records
* 638 MEDIUM risk records
* 222 HIGH risk records
* 35 CRITICAL risk records

The dashboard presents this distribution to support risk monitoring.

## 8. ML Monitoring

The dashboard displays prediction confidence categories and monitoring levels.

The prediction monitoring dataset contains:

* 1,767 HIGH CONFIDENCE predictions
* 18 MEDIUM CONFIDENCE predictions
* 0 LOW CONFIDENCE predictions

The mean prediction confidence is approximately 0.995.

## 9. Container-Level Analysis

The dashboard calculates predicted anomaly rates for each container.

* CONT_002: 10.32%
* CONT_003: 10.03%
* CONT_004: 9.92%

## 11. Spoilage Arbitrage Monitoring

The dashboard visualizes the recommended operational actions generated by the Day 7 decision engine.

The decision categories include:

* CONTINUE MONITORING
* INCREASE MONITORING

## 12. Dashboard Purpose

The dashboard provides a single analytical interface for monitoring:

```text
Telemetry
    ↓
Environmental Risk
    ↓
Spoilage Risk
    ↓
ML Prediction
    ↓
Prediction Monitoring
    ↓
Operational Decision
```

## 13. Limitations

The current system uses simulated telemetry rather than production IoT data.

Therefore:

* The dashboard does not represent actual field measurements.
* Risk categories are based on predefined analytical rules.
* ML confidence should not automatically be interpreted as a calibrated probability.
* Predicted anomalies are model outputs.
* Potential arbitrage opportunities are decision-support outputs rather than confirmed financial arbitrage.
* The dashboard does not establish causal relationships between sensor variables and spoilage.
